# SVoice downloads

Installers and update files for SVoice, a voice dictation app for the desktop.

## Install

Get the latest version from the [Releases](../../releases/latest) page.

| Computer | File |
| --- | --- |
| Mac with Apple silicon (M1 or newer) | `SVoice_<version>_aarch64.dmg` |
| Windows, 64-bit | `SVoice_<version>_x64-setup.exe` |

The installers are not yet code-signed, so the operating system warns on first launch.

- **macOS:** open the `.dmg`, drag SVoice into Applications and open it. When macOS blocks it, open **System Settings → Privacy & Security** and choose **Open Anyway**.
- **Windows:** on the SmartScreen warning choose **More info**, then **Run anyway**.

After that, SVoice updates itself.
